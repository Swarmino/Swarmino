## About me

I'm a developer and designer from Norway focused on building **modern user interfaces and the systems that power them**.

My background spans frontend development, mobile applications, game development and UI/UX — which means I tend to look at software as a complete product rather than just a collection of components.

I'm particularly interested in:

- ⚡ Modern frontend architecture
- 🧩 Design systems & reusable UI
- 🏗️ Application and system architecture
- 🎨 Bridging design and development
- 🤖 AI-assisted tools and workflows
- 🎮 Interactive experiences & game development
- 📱 Cross-platform applications
